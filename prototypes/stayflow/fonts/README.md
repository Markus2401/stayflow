# Local prototype type

These unmodified variable TTFs and their SIL Open Font License 1.1 notices were fetched from [Google Fonts at 7af0d90](https://github.com/google/fonts/tree/7af0d90b4d532ffa4b041937b560c6df4e7b1e95/ofl). CSS loads each font from this folder.

| Local file | Source path |
|---|---|
| `geist.ttf` | `ofl/geist/Geist[wght].ttf` |
| `source-sans-3.ttf` | `ofl/sourcesans3/SourceSans3[wght].ttf` |
| `atkinson-next.ttf` | `ofl/atkinsonhyperlegiblenext/AtkinsonHyperlegibleNext[wght].ttf` |

The small line icons and wordmark geometry were drawn for this prototype. The prototype uses no icon library or external artwork.
